⚡ Inicializar Tablas en tu Proyecto Supabase

Tu proyecto de Supabase (vgvijpknawgrjctywywq) está conectado. Para que las reservas se guarden de forma permanente en la nube, solo necesitas crear la tabla una sola vez:

🔗 Abrir SQL Editor de Supabase ↗
  1. Haz clic en "📋 Copiar Script SQL".
  2. Haz clic en "🔗 Abrir SQL Editor de Supabase" para entrar directamente a tu proyecto.
  3. Pega el código copiado en la ventana negra del editor.
  4. Pulsa el botón verde "RUN" (abajo a la derecha en Supabase).
  5. Vuelve a esta pantalla y pulsa "🔄 Probar Conexión Ahora". ¡Las reservas quedarán 100% activas y permanentes!
Ver código SQL completo (o copiar manualmente) 
-- ========================================================
-- TABLA DE RESERVAS PARA TETERÍA BODHI (SUPABASE)
-- ========================================================
CREATE TABLE IF NOT EXISTS public.reservations (
  id BIGSERIAL PRIMARY KEY,
  code VARCHAR(50) UNIQUE NOT NULL,
  name VARCHAR(255) NOT NULL,
  phone VARCHAR(100) NOT NULL,
  email VARCHAR(255),
  date VARCHAR(50) NOT NULL,
  time VARCHAR(50) NOT NULL,
  guests INT NOT NULL DEFAULT 2,
  zone VARCHAR(100) DEFAULT 'indiferente',
  notes TEXT,
  status VARCHAR(50) DEFAULT 'pending',
  admin_notes TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

ALTER TABLE public.reservations ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Permitir crear reservas" ON public.reservations;
CREATE POLICY "Permitir crear reservas" ON public.reservations FOR INSERT WITH CHECK (true);

DROP POLICY IF EXISTS "Permitir leer reservas" ON public.reservations;
CREATE POLICY "Permitir leer reservas" ON public.reservations FOR SELECT USING (true);

DROP POLICY IF EXISTS "Permitir actualizar reservas" ON public.reservations;
CREATE POLICY "Permitir actualizar reservas" ON public.reservations FOR UPDATE USING (true);

DROP POLICY IF EXISTS "Permitir eliminar reservas" ON public.reservations;
CREATE POLICY "Permitir eliminar reservas" ON public.reservations FOR DELETE USING (true);

CREATE TABLE IF NOT EXISTS public.menu_items (

  name VARCHAR(255) NOT NULL,
  description TEXT,
  price NUMERIC(8, 2) NOT NULL,
  badge VARCHAR(100),
  image TEXT,
  available BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP

ALTER TABLE public.menu_items ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Lectura publica carta" ON public.menu_items;
CREATE POLICY "Lectura publica carta" ON public.menu_items FOR SELECT USING (true);

DROP POLICY IF EXISTS "Modificar carta" ON public.menu_items;
CREATE POLICY "Modificar carta" ON public.menu_items FOR ALL USING (true);

🟢 1. Conexión en Vercel (PostgreSQL Cloud)

Para persistencia permanente en Vercel, utiliza un servicio gratuito como Neon.tech, Supabase o Vercel Postgres.

  1. Crea una base de datos gratis en Neon.tech o Supabase.com.
  2. Copia tu cadena de conexión (URI) que empieza por postgres://...
  3. En tu proyecto de Vercel ve a Settings → Environment Variables.
  4. Añade la variable DATABASE_URL con tu enlace.
  5. ¡Listo! Las tablas de reservas y carta se inicializan automáticamente.

🟡 2. Modo Local / Respaldo

Si no se configura DATABASE_URL, la aplicación guarda las reservas en archivos locales en data/reservas.json.

npm run dev

📲 Notificaciones Automáticas en tu Móvil

Elige el canal que prefieras para enterarte de cada reserva al instante en tu teléfono:

💬 Opción 1: WhatsApp al Móvil (CallMeBot Gratis)

Recibe un WhatsApp automático a tu móvil personal cada vez que un cliente reserva:

  1. Envía por WhatsApp al número +34 644 10 55 84 el texto: I allow callmebot to send me messages
  2. Te responderá en segundos con tu apikey.
  3. En Vercel (Settings → Environment Variables) añade:
    WHATSAPP_NOTIFY_PHONE=346XXXXXXXX
    WHATSAPP_NOTIFY_APIKEY=tu_apikey

✈️ Opción 2: Telegram Bot (Gratis)

Crea un bot de avisos exclusivo para tu tetería en Telegram:

  1. En Telegram busca @BotFather y escribe /newbot.
  2. Copia el token que te proporcione.
  3. En Vercel añade:
    TELEGRAM_BOT_TOKEN=123456:ABC...
    TELEGRAM_CHAT_ID=tu_chat_id

✉️ Opción 3: Correo Electrónico (Resend)

Recibe un email con todos los datos detallados:

  1. Crea cuenta gratis en resend.com.
  2. Copia tu API Key de Resend.
  3. En Vercel añade:
    RESEND_API_KEY=re_...
    ADMIN_EMAIL=tu@correo.com
